# Beta47: prueba de accesorios permanentes

Escribe experiencia de armas en el perfil usando las funciones DDL nativas de Mac v98. Usa el máximo requisito de cada tabla de arma, conserva experiencia mayor y verifica cada escritura en memoria. Solicita el guardado y registra la operación una vez por modo. Mantiene nivel objetivo 997.

Instalar con el nuevo .command, reiniciar, esperar 10 segundos en cada menú. Cerrar normalmente y ejecutar Comprobar desbloqueos guardados.command para desactivar todos los desbloqueos simulados antes de revisar después del reinicio.

La persistencia real debe confirmarse en el juego. Camuflajes por desafíos y GobbleGums no se hacen permanentes en esta beta. El respaldo local se guarda antes de instalar; no se garantiza el inventario del servidor.
